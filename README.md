# 🎮 Mini Desafio HTML - Loja de Games Retro

## 📋 Descrição do Desafio
Este repositório contém a solução do mini desafio de desenvolvimento web. O objetivo é criar uma página promocional funcional para a **GameZone Retro**, uma loja especializada em jogos clássicos, mostrando o domínio dos conceitos fundamentais de HTML.

## 🎯 Objetivo
Construir uma página web estruturada de forma organizada com o limite rigoroso de **no máximo 50 linhas de código**.

## 📝 Requisitos do Projeto

### 🧱 Elementos Essenciais
* **Estrutura básica:** Título e parágrafos com formatações de texto em **negrito** e *itálico*.
* **Lista:** Uma lista detalhando consoles ou jogos.
* **Navegação:** Pelo menos um link interno e um link externo funcional.
* **Imagem:** Uma foto/elemento visual relacionado ao tema retrô.
* **Tabela:** Uma tabela simples de produtos e preços com no mínimo 3 itens.

### 🔧 Especificações Técnicas
* **Tecnologia:** HTML5 puro e simples.
* **Limite:** Máximo de 50 linhas de código.
* **Foco:** Código limpo, válido e organizado.
